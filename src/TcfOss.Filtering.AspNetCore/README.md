# TcfOss.Filtering.AspNetCore

ASP.NET Core middleware helpers for handling malformed filter payloads.

## What this package adds

- Middleware to catch filter deserialization exceptions and convert them into API-friendly responses.

## Typical usage

Register the middleware in your ASP.NET Core pipeline where you handle request errors.
