TcfOss.Filtering Demo

Standard request — POST /employees

Whitelist: Department.* — direct children only. Filtering on Department.Name works; Department.Office.City would be blocked.

Note that the demo project queries an in-memory collection, not a real database, so string comparisons are case-sensitive.

Dynamic request — POST /employees/dynamic

Whitelist: Department.** — all descendants. Both Department.Name and Department.Office.City are permitted.

Blacklist: Department.Office.SecretId — takes precedence over whitelist.
